# GitHub Final Project

## Simple Interest Calculator

This project is a simple interest calculator created using a Bash script. It calculates simple interest based on the principal amount, annual rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Features

- Accepts principal amount as user input.
- Accepts annual rate of interest as user input.
- Accepts time period in years as user input.
- Calculates and displays the simple interest.
- Uses a Bash script to perform the calculation.

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal and enter the requested values.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
